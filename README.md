# 🎓 Student Grade Calculator

## Project Overview

The Student Grade Calculator is a beginner-friendly Python project that calculates a student's grade based on their marks.

The program accepts the student's name and marks, validates the input, calculates the appropriate grade, and displays an encouraging message.

## Features

- Accepts student name
- Accepts marks between 0 and 100
- Validates incorrect marks
- Handles non-numeric input
- Calculates grades using if-elif-else
- Uses functions
- Uses a while loop for input validation
- Displays encouraging messages

## Grade Rules

| Marks | Grade | Message |
|---|---|---|
| 90–100 | A | Excellent work! Keep shining! |
| 80–89 | B | Very good! Keep it up! |
| 70–79 | C | Good effort! Keep improving! |
| 60–69 | D | You passed! Keep practicing! |
| 0–59 | F | Don't give up! Learn and try again! |
